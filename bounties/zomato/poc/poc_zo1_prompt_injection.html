Step 2: Victim Connects Zomato MCP to Their LLM

OAuth Flow:
GET https://mcp-server.zomato.com/authorize
  ?client_id=CLAUDE_DESKTOP_CLIENT
  &redirect_uri=claude://mcp-callback
  &scope=mcp:tools mcp:resources
  &response_type=code
  &code_challenge=S256_CHALLENGE

→ Victim logs in with phone OTP
→ LLM receives Bearer token
→ LLM can now call all 13 MCP tools with victim's identity

Attack requires:
  ✓ Attacker: Zomato restaurant account (freely registerable)
  ✓ Victim: Zomato MCP connected to an LLM client (Claude, Copilot, etc.)
  ✓ Trigger: Victim asks about restaurants
  ✗ No vulnerability in the LLM itself required — attack uses the designed tool flow

This is an INDIRECT prompt injection — the LLM is not directly attacked,
the data pipeline (restaurant DB → MCP tool response → LLM context) is the vector.
